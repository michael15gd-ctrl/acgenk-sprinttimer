Starttelefoon koppelen

Beide smartphones zitten op hetzelfde wifi-netwerk. De starttelefoon hoeft alleen deze QR-code te scannen.

Aankomsttelefoon

Maak één sessie aan. Toon daarna de vierkante QR-code op dit scherm. De starttelefoon scant deze code met de gewone Camera-app.

De QR-code wordt volledig in de app gemaakt. Voor het koppelen gebruikt deze testversie PeerJS-signaling; daarna loopt de timingcommunicatie rechtstreeks tussen de gekoppelde telefoons.

Starttelefoon

Open de gewone Camera-app van deze smartphone en richt op de vierkante QR-code op de aankomsttelefoon. Tik daarna op de melding om de Sprint Timer te openen. De app koppelt automatisch.
